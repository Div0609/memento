# Delegate Memento — Presentation Cabinet

Static site. Host on GitHub Pages: push this folder, then Settings → Pages → deploy from branch (root).

- index.html — concept board
- cabinet-3d.html — interactive 3D model (append ?open=0 for the closed state); downloads OBJ+MTL / GLB
- three-d-stage.js — viewer
- memento.jpg — reference photo

three.js loads from unpkg; needs internet.
